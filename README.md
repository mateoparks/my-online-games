## Escape from Alpha Centauri controls

Move with A/D or the arrow keys, mine with Space, and use nearby world objects
with E. Q opens quests and recovered memories; I opens carried inventory.
Using E at the salvage cache opens its saved-material transfer and progression
panel. The always-available **Start new expedition** control asks for
confirmation before clearing the saved expedition and restoring the baseline.
